# التعمير · El Taamir · المدية — إصدار الويب 2

افتح `index.html` عبر رابط الموقع، أو شغّل خادمًا محليًا من هذا المجلد (`python3 -m http.server 8765`) ثم افتح `http://127.0.0.1:8765/`.

- تتضمن الواجهة خريطة عامة عبر الإنترنت وسجل معاينة محليًا، ورسم حدود يدويًا لحساب مساحة تقريبية، وصورًا وأدلة، ومقارنة وحاسبة ودليل تحقق.
- سجلات المعاينة والصور تبقى على الجهاز/المتصفح نفسه؛ لا توجد مزامنة تلقائية بين الأجهزة. صدّر نسخة احتياطية من الواجهة عند الحاجة.
- بيانات PDAU/POS من نص قدّمه المستخدم ولم تُراجع على العرض الأصلي. بطاقات الأراضي الـ15 وأسعارها ومساحاتها أمثلة افتراضية، لا عروض بيع ولا مواقع حقيقية؛ لا إحداثيات أو حقوق بناء مختلقة.
- الخريطة لا تعرض حدودًا رسمية للولاية/البلديات أو قطع الأراضي. القياس اليدوي تقريبي ولا يثبت الملكية أو الحدود المساحية. استخدم الوثائق الأصلية والجهات المختصة.
- هذه نسخة ويب تجريبية، وليست ملف APK أو نظامًا رسميًا.
