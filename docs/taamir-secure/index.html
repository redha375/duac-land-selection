إدارة حسابات الفريق

الحسابات الجديدة تبدأ موقوفة. اختر الدور والحالة ثم احفظ؛ يرفض الخادم أي تغيير لا يجريه مدير مخوّل.

إعداد Supabase: نفّذ ملف supabase-secure.sql على مشروع Supabase جديد أو راجعه مع مسؤول قاعدة البيانات قبل الترحيل. ثم أدخل Project URL و anon public key فقط؛ لا تضع service_role key هنا.

وضع المعاينة المحلي منفصل عن بيانات الفريق. لا ترفع أي سجل محلي تلقائياً؛ سجّل الدخول بصلاحية فعالة لقراءة/تعديل سجلات Supabase. لا تضع أسرارًا أو مفاتيح service_role في الواجهة.
