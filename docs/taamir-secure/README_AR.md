# التعمير — النسخة الآمنة 3.4 التجريبية

[افتح التطبيق](./index.html) · [ملف إعداد Supabase الآمن](./supabase-secure.sql)

هذه نسخة ويب/PWA جديدة من واجهة DUAC Médéa، مع صلاحيات الفريق التي يفرضها PostgreSQL عبر RLS: مالك التطبيق وحده يدعو المستخدمين ويعيّن أدوارهم ويفعّلهم؛ المدير يدير السجلات؛ العون يقرأ ويضيف ويعدّل ويرفع PDF؛ والمراقب يقرأ السجلات والملفات فقط. دور المدير لا يمنح حق إدارة المستخدمين.

## الإعداد اللازم قبل الاستخدام الجماعي

- أنشئ مشروع Supabase جديدًا ومخصصًا لهذا التطبيق؛ لا تشغّل الترحيل على مشروع حالي قبل مراجعة أثر أسماء الجداول وسياسات الوصول.
- نفّذ `supabase-secure.sql` في SQL Editor، ثم أنشئ حساب المالك من التطبيق وأكّد بريده. شغّل `owner-bootstrap.template.sql` في SQL Editor بعد استبدال `YOUR_LOGIN_EMAIL` ببريد حسابك هناك فقط؛ لا تحفظ البريد في هذا المستودع. لا يستبدل القالب مالكًا سبق تهيئته ببريد آخر.
- انشر وظيفة الدعوات من جذر المستودع بعد ربط Supabase CLI بالمشروع: `supabase functions deploy admin-invite-member`. تأكد أن بيئة الوظيفة تحتوي مفاتيح Supabase الخادمية، خصوصًا `SUPABASE_SERVICE_ROLE_KEY`؛ لا تضع هذا المفتاح في الواجهة أو GitHub.
- اضبط Site URL وRedirect URLs في إعدادات Auth على عنوان HTTPS الفعلي للتطبيق، واضبط بريد الإرسال في Supabase. اربط التطبيق بـ Project URL ومفتاح `anon` / publishable فقط.
- سجّل بحساب المالك وافتح «إدارة المستخدمين والصلاحيات» لإرسال دعوة. بعد إرسالها يظهر الحساب موقوفًا؛ عيّن له دورًا وفعّله بعد قبول الدعوة. حسابات المدير الأخرى لا تستطيع إدارة المستخدمين. طلبات التسجيل العادية، إن استُخدمت، تبقى موقوفة حتى تفعيلها من المالك.
- سجلات الفريق والـPDF لا تُحمّل قبل دخول عضو فعّال. ملفات PDF خاصة وتُفتح بروابط مؤقتة بعد تحقق الخادم. الخريطة تتطلب الإنترنت.

الترحيل ووظيفة الدعوات لا يُطبّقان تلقائيًا على خدمة مستضافة، ولا يحتوي هذا النشر على بيانات اعتماد لمشروع Supabase. يجب على المالك تشغيل SQL، تهيئة حسابه، ونشر وظيفة الدعوات قبل استخدامها. بيانات 3.2 السابقة لا تُرفع أو تُدمج تلقائيًا.

## حدود النسخة

هذه نسخة ويب تجريبية وليست APK. لم تُنشر إعدادات Supabase أو وظيفة الدعوات على مشروع حي ولم تُختبر حسابات الأدوار فعليًا؛ اختبارات المصدر تؤكد قواعد المصدر فقط. لا تستخدم بيانات رسمية أو شخصية حساسة قبل تهيئة مشروع مخصص واختبار المالك والمدير والعون والمراقب. إصدار Android الميداني الفارغ 2.3.0 محفوظ دون تغيير.
